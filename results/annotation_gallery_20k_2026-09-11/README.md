# Fifty qualitative comparisons

Generated by `scripts/make_annotation_gallery.py` for the private annotation
gallery. The frozen manifest pins the existing 20k seed-0 checkpoint, sampling
rule, allowed evaluation recordings, calibration report and inference code.
Each example includes an exact cropped probability map, binary mask,
spectrogram, clipped references, and checksums linking them to the displayed PNGs.

The model is Large with a 128-wide, one-layer head, trained on hard masks.
Its best XC-validation epoch is 3 of 5. Use the Powdermill-selected 0.13
threshold with Gaussian probability smoothing, sigma 2 mel bins / 3 frames.
All overlapping-window predictions and smoothing are computed on the full
recording before cropping. Training and benchmark tables are unchanged.

There are 10 distinct recordings per dataset, sampled using seed 17 from
eligible positive-reference recordings; one random human event anchors each
up-to-five-second excerpt. Powdermill uses Recording 1 only. Other datasets
retain the existing external manifest exclusions. Sampling is reference-aware
but prediction-blind, and is not a representative benchmark sample.

XC-AJ and NIPS4Bplus show time-only references. The predicted contours remain
two-dimensional. Their displayed frequency extent is not a human reference
or a claim of frequency-localization accuracy. Unknown NIPS4Bplus intervals
are hatched. Only the 100 PNG panels and sanitized gallery metadata are hosted;
no model weights, raw recordings, or full annotation datasets are uploaded.
